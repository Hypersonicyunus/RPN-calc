# Reverse Polish Notation Calculator CLI Tool
Hey there! Thanks for checking out my cli tool! This .readme is going to be a guide for you to help understand what the tool is and how to use/install it.

# What is Reverse Polish Notation (RPN)?
RPN is a way to express an equation without the need of brackets. It works by using writing tokens, which are operands (numbers) and operators (+,-,*,/).

# How is RPN calculated?
RPN is calculated by using the first two tokens (that are operands) before an operator, and calculating them like you usually would. Here is a visual example:
